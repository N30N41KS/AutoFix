# AutoFix — Учёт заявок автосервиса

Мобильное приложение для оперативного учёта заявок на слесарный ремонт и малярные работы автосервиса с локальной базой данных SQLite.

## Стек технологий
* **ОС / Платформа:** Android (API 24+)
* **Язык разработки:** Java
* **Хранение данных:** SQLite (SQLiteOpenHelper + Repository pattern)
* **Архитектура UI:** Multi-Activity (ScrollView, LinearLayout, TableLayout)
* **Система контроля версий:** Git / GitHub

## Структура приложения
* `MainActivity` — Главный экран: динамические часы, таблицы активных заявок (ремонт/покраска), сортировка по дате и алфавиту.
* `create_repair` — Форма регистрации слесарного ремонта с валидацией и выбором даты/времени.
* `create_paint` — Форма регистрации малярных работ (с указанием цвета кузова).
* `stats` — Сводная статистика по статусам («Всего», «В работе», «Выполнены») и списки последних записей.
* `DbHelper` / `RequestRepo` — Слой локальной базы данных `autofix.db` с индексами и механизмом начального наполнения `seedIfEmpty()`.
